# template仕様

## 責務

`src/template/`は、スタンドアロンHTML文書の外枠と共通埋め込みCSSを所有する。Markdown解析、ファイル探索、HTTP配信は扱わない。

## ファイル

### `document.ts`

- `DocumentParts`: title、language、本文に加え、配置済みマークアップを`regions`、埋め込みCSSとJavaScriptを`assets`として受け取る内部型。Feature追加によるトップレベル項目の増殖を防ぐ。
- `renderDocument(parts)`: doctypeからbody末尾まで、通常本文、Markdown原文、任意の差分本文、共通の文書操作を同じ本文グリッド領域へ配置した単一HTML文字列を生成する。
- `trustedScript()`: marksites自身の実行スクリプトへ`data-marksites-script="true"`を付け、サーバーCSPの照合対象にする。

固定ヘッダーは全ページへ描画し、従来のブランド位置に文書ナビゲーションを内包する。ファイルツリーがある場合だけ`has-file-tree` classとパンくず・ツリー用スタイルを追加する。常設ファイルサイドバーは画面左端へ固定し、グリッドの左カラムを同じ幅だけ確保する。開閉トグルは固定ヘッダー左端へ重ね、サイドバーをヘッダーより前面に配置して常に操作可能にする。ヘッダー本文はトグル分だけ左余白を持つが、サイドバー内の見出しには追加の左余白を設けない。パンくずでは祖先がある現在ファイルの直前にだけ`/`区切りを表示して文字の縦位置を揃え、ルート文書では区切りを省略する。パスコピーボタンはアイコンをボタン中央に配置する。ポップオーバー用ツリーは固定ヘッダーの文書メタ情報を相対配置コンテナとして開く。更新日時はファイルパスの右隣へ中点区切りで表示し、狭い画面では非表示にする。highlight無効時はhighlightテーマを埋め込まない。`assets`の配列順を出力順として扱い、スクリプトの順序はヘッダー、ファイルツリー、更新日時、サイドバー、目次、コードブロック、コメントとする。

HTML、Markdown原文、差分本文は共通の枠を持つ`document-content`内で排他的に表示する。文書操作はその枠内上部の全幅行へ左揃えで置き、下境界線で本文と区切って表示を切り替えても同じ位置を維持する。

### `styles.ts`

- `githubMarkdownCss`: `github-markdown-css`のCSSをビルド済みモジュール読み込み時に取得する。
- `highlightCss`: highlight.jsのGitHubテーマを取得する。
- `highlightThemeStyles`: 明示的なダークテーマ選択時にhighlight.jsの背景、通常文字、構文トークンをGitHub Dark相当のテーマ変数へ切り替える。highlight無効時は埋め込まない。
- `documentStyles`: 本文と右サイドバーのグリッド、目次パネル、コードツール、更新日、基本レイアウトを定義する。下余白はbodyのpaddingではなく本文のgrid marginとして確保し、ページ末尾でもstickyサイドバーが親グリッド下端に押し上げられないようにする。目次の内側へ`min-height: 100%`を指定せず、外側パネルのpaddingによる不要なオーバーフローを防ぐ。タブとコメント固有のスタイルは各featureが所有する。
- `fileTreeStyles`: 画面左端へ接する幅280px・全高の常設ファイルペイン、その開閉時の3カラム・2カラム切り替え、固定ヘッダー左端の枠なしペイン開閉アイコン、現在ファイル名を使うリンク風ポップオーバートリガー、ツリー・更新順タブ、折り畳み可能な日付グループ、左側の固定幅時刻列、連続ファイルのフォルダ見出し、パスコピー、コメント件数バッジを定義する。常設ペインは角丸やカード状の外周枠を持たず、右境界線だけを表示する。更新順のツリーガイド線は一覧内容の背面へ配置し、日付行の背景で遮る。日付アイコン上へ縦長の背景マスクを重ねない。900px以下では固定オーバーレイにして本文幅を維持する。パンくずの各テキストセグメントと区切りは共通の28px line-heightとbaselineで文字位置を揃え、操作SVGは文字の視覚中心に合わせて補正する。GitHub本文CSSが`details`へ付ける16pxの下余白は、ツリー内に限って0へリセットする。

CSSは生成HTMLへ直接埋め込み、CDNや実行時ファイル参照を追加しない。

## 不変条件

- 出力は完全なHTML文書で末尾改行を持つ。
- title、languageなど外部値は呼び出し側でエスケープ済みであることを前提とする。
- Markdown由来の任意scriptをtrusted scriptとしてマークしてはならない。
