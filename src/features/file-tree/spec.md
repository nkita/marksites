# file-tree仕様

## 責務

ファイルツリー、常設ファイルサイドバー、パンくず、更新日時と、それらに必要なブラウザ動作を所有する。

## ファイル

- `index.ts`: マークアップ生成とブラウザスクリプトを構成する内部エントリポイント。

出力互換性を保ちながら分割する場合は、マークアップ、スタイル、ブラウザ動作をこのフォルダ内に置く。

ファイル一覧は従来のディレクトリツリーと更新順表示を切り替えられる。更新順表示はISO 8601の`modifiedAt`を新しい順に並べ、左端のツリーガイド風の縦線からインデントした位置に通常ウェイトのファイル名、右端に有効コメント件数を表示する。日時は一覧に表示しない。親ディレクトリは通常時には表示せず、ファイル行のhoverまたはキーボードフォーカス時に、ファイル名の文字列末尾から8px右側へフォルダアイコンと左向きの三角を持つ明色の吹き出しを遅延なく表示する。吹き出しには親ディレクトリとローカルタイムゾーンの更新日時を表示し、固定座標でサイドバーのクリップを避け、画面端を越えない範囲に収める。パスは変換ルートを`/`、配下を`/src/`とする。ファイル名の下線はhover時だけ表示する。同じ日付内で同一の親ディレクトリが2件以上連続しても表示上の並び順は変えない。

日付見出しはchevron、ローカル日付、ファイル件数を持つ折り畳みボタンとする。初期状態では最新日と現在ファイルを含む日を展開し、それ以外を閉じる。開閉状態は常設側とポップオーバー側で同期するがURLには保存しない。検索中は一致ファイルを含む日を一時的に展開し、検索解除時は検索前の開閉状態へ戻す。

吹き出し内の親ディレクトリはエスケープする。生成時はUTC日付でグループ化し、ブラウザ実行時にローカルタイムゾーンの日付と内部的なフォルダ区間を再構築する。同一日時はルート相対パスの英語locale順とする。`modifiedAt`がないファイルは更新順表示から除外し、不正な値は拒否する。

ファイルは有効コメント件数をバッジ表示し、各ディレクトリは配下の全ファイルにある有効コメント件数の合計を再帰的にバッジ表示する。0件のバッジは表示しない。閉じたディレクトリでは配下の合計バッジを表示し、開いたディレクトリでは子要素のバッジとの重複を避けるため合計バッジを非表示にする。

ファイルパスのコピーはセキュアコンテキストでClipboard APIを優先し、権限拒否を含む書き込み失敗時は一時textareaと`execCommand("copy")`へフォールバックする。両方が失敗した場合だけ失敗として表示する。
