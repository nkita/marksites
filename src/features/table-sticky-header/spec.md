# table-sticky-header仕様

## 責務

Markdown本文の表をページスクロールしている間、先頭見出し行の複製を固定サイトヘッダー直下へ表示する。

## 動作

- 元の見出しが上端56pxより上へ移動し、表末尾が固定見出しの下にある間だけ表示する。
- 固定見出しの左位置、各列幅、横スクロール位置を元の表へ同期する。表示幅は表の実幅と横スクロール領域の表示可能幅の小さい方とし、列が少ない表の右側へ背景、境界線、影を延長しない。
- 列幅変更とウィンドウ幅変更は`ResizeObserver`で追従し、未対応ブラウザでもスクロールとresizeイベントで再計算する。
- 固定見出しをクリックした場合は元の見出しへ操作を委譲し、ソート状態を`aria-sort`へ同期する。
- 複製は`aria-hidden`として支援技術から除外し、元の表だけを意味上の表として維持する。
- 固定見出しはサイトヘッダーより背面、本文より前面に表示し、ライト・ダークテーマに対応する。
- 表がない文書にはスタイルとスクリプトを埋め込まない。

## ファイル

- `index.ts`: 有効時だけ固定見出し用スタイルとブラウザスクリプトを返すFeature内部エントリポイント。
