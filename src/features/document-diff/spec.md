# document-diff仕様

## 責務とファイル

- `blocks.ts`: Markdownのブロック列をLCSで比較し、同一ブロックを基準点にする。
- `alignment.ts`: 順序を保つ対応付けと文字bigramの類似度。完全一致を優先し、類似度が低い要素は独立した追加・削除にする。比較行列が250,000要素を超えた場合は全削除・全追加へ退避する。
- `inline.ts`: インライン構造を保持した左右別の語句差分。日本語の語句はIntl.Segmenterで分割する。
- `index.ts`: 左に前バージョン、右に現バージョンを持つ対応行と構造別の差分を生成する。
- `presentation.ts`: 差分専用CSSと行高同期スクリプトを所有する。外部資源には依存しない。

## 表示と対応付け

前回正常ビルド時と現在のMarkdownを比較する。同一ブロックの間の変更群を種類と内容の類似度で対応付ける。各対応行を等幅2列のCSS Gridにし、高い側に合わせて次の段落・見出しの開始位置を揃える。片側だけのブロックには反対側に薄いグレーの空白を置く。

本文は12px・行間1.6、コードは11px。削除は左側に赤い文字と薄い赤背景、追加は右側に青い文字と薄い青背景で示す。差分用のins/delには取り消し線も下線も付けない。Markdown原文自身の取り消し線は保持する。列名と配置によっても前後を区別し、ダークテーマに対応する。縦スクロールは共通。640px未満では2列を維持して比較領域を横スクロールする。

見出し・段落は語句単位で強調する。コード行、単純なリスト項目、同じ列数の表の行、単純な引用段落は内部でも対応付け、同数の行スロットを生成する。ブラウザで各ペアの自然高を計測し、大きい方へ合わせる。プレビュー等からの切り替え、列幅変更、画面リサイズ、画像読込、フォント読込後に再計測する。ResizeObserverは幅の変化だけを再計測の契機にし、自身の高さ変更によるループを防ぐ。段落内の折り返し行までは揃えない。

入れ子・タスク・複数段落のリスト、複雑な引用、列数が変わる表、未対応構造は左右それぞれのMarkdownをブロックとして描画し、内容を欠落させずブロックの開始位置を揃える。

## 既存機能との境界

通常本文と差分本文は別mainとし、注釈と文字列置換は通常本文だけを対象にする。見出しIDは前版をdiff-old-、現版をdiff-で分離し、各版で独立したGitHub互換slugを生成する。目次は現版の見出しを参照する。

リンクは各版のリンク先を保持し、URL変更時は各側にそのURLを表示する。前版の操作要素はクリックとフォーカスを無効にする。左右とも装飾とリンク構造を保持する。

差分切り替えボタンは本文操作行の`プレビュー`、`コード`の右に配置し、差分のない場合は非活性にする。表示状態とURLはdocument-viewが所有する。行高同期スクリプトはregistryに登録し、HTTP配信時のCSPでも実行できるようにする。
