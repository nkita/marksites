# document-diff仕様

前回正常ビルド時のMarkdownと現在のMarkdownをトップレベルのMarkdownブロック単位で比較し、同一ブロックの順序を維持しながら追加と削除をHTML表示する。対応する見出し、プレーンな段落、リスト項目、表セル、引用内の段落では語句単位でも比較し、変更された語句だけを控えめな背景色の`ins`と`del`で示す。コードブロックは行を整列して、対応する変更行では語句差分、行全体の追加・削除では行単位の差分を表示する。完全に追加または削除された要素と、安全に構造内へ差分を埋め込めないMarkdownはブロック単位で表示する。

追加は青系の二重下線、削除は識別しやすい抑制された赤系の文字色と取り消し線を使う。色覚差に配慮して色だけには依存せず、ブロック差分には`+`と`−`、実線と破線も併用する。完成後の文書DOM、目次、注釈、ナビゲーションは比較対象に含めない。

リンクはHTMLの`a`要素を維持して比較する。表示文字列の変更はリンク内の語句差分として示し、リンク先の変更は現在のリンクに旧URLと新URLの補助表示を添える。リンク全体の追加・削除はインライン要素単位で示し、削除されたリンクはクリックおよびキーボードフォーカスを無効にする。太字、斜体、取り消し線、インラインコードなど、対応するインライン要素も可能な範囲でHTML構造を維持する。

通常本文と差分本文は別の`main`要素として生成し、注釈および文字列置換の探索対象を通常本文に限定する。差分内の見出しにもGitHub互換IDを生成して`diff-`接頭辞を付け、通常本文と重複させない。右サイドバーと目次は差分表示でも維持する。削除された操作要素は操作不能にする。

固定ヘッダーではダークモード切り替えの左隣にinline SVGの切り替えボタンを表示する。差分がない場合は非活性にする。HTML、Markdown原文、差分の排他的な表示状態とURLへの反映は`document-view` featureが所有する。差分のないページでは最新版を表示するが、URL上の差分表示意図はリンク先へ維持する。
