# document-diff仕様

前回正常ビルド時のMarkdownと現在のMarkdownをトップレベルのMarkdownブロック単位で比較し、同一ブロックの順序を維持しながら追加と削除をHTML表示する。対応するプレーンな段落では語句単位でも比較し、変更された語句だけを控えめな背景色の`ins`と`del`で示す。追加は青系の二重下線、削除は通常の文字色と取り消し線を使い、赤と緑の識別に依存しない。ブロック差分には`+`と`−`、実線と破線も併用する。Markdown装飾を含むなど安全にインライン化できないブロックと、ブロック全体の追加・削除はブロック単位で表示する。完成後の文書DOM、目次、注釈、ナビゲーションは比較対象に含めない。

通常本文と差分本文は別の`main`要素として生成し、注釈および文字列置換の探索対象を通常本文に限定する。差分内の見出しにもGitHub互換IDを生成して`diff-`接頭辞を付け、通常本文と重複させない。右サイドバーと目次は差分表示でも維持する。削除された操作要素は操作不能にする。

固定ヘッダーではダークモード切り替えの左隣にinline SVGの切り替えボタンを表示する。差分がない場合は非活性にする。差分表示状態は`document-view=diff`へ保存し、同一ホスト・プロトコルのHTMLリンクへ引き継ぐ。差分のないページでは最新版を表示するが、URL上の差分表示意図はリンク先へ維持する。
