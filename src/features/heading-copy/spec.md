# 見出しパスコピー

プレビュー本文の`h1`から`h6`へ見出しパスのコピーアイコンと、その右隣に見出しURLのリンクアイコンを追加する。アイコンは初期状態では非表示とし、見出しへのホバーまたはボタンへのキーボードフォーカス時に表示する。

コピー値はMarkdownファイルの変換ルート相対パスを先頭に置き、`#`に続けて対象見出しまでの親見出しを見出しレベルから特定し、`>`で連結する。たとえば`docs/guide.md#章>節`とする。同じレベルまたは浅いレベルの見出しへ進んだ場合は、以前の子階層を引き継がない。

Clipboard APIが利用できない`file://`表示では、一時的なtextareaと`document.execCommand('copy')`を代替処理として使う。コード表示と差分表示の見出しには操作を追加しない。

リンクアイコンは現在の文書URLのfragmentを対象見出しのGitHub互換IDで置き換えた絶対URLをコピーする。現在の言語、テーマ、表示設定などのクエリパラメータは維持する。アイコンは24×24のviewBox内に、180度回転対称の2本の開いた輪郭で斜めのチェーンを描く。中央の独立した接続線をなくして交差部の潰れを避け、線幅2.5・丸い端点と接合部で、他の見出し操作アイコンと同じ14pxで表示する。
