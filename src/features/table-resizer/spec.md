# table-resizer仕様

## 責務

Markdown本文に表がある場合、各列の境界全体へ列幅変更ハンドルを追加する。機能のスタイルとブラウザJavaScriptは生成HTMLへ埋め込み、外部リソースへ依存しない。

## 動作

- 表の上端から下端まで伸びる各列境界をPointer Eventsでドラッグすると、その列の幅を変更する。見出し以外の行からも操作できる。
- マウスの主ボタン、タッチ、ペンを受け付け、操作中はポインターをハンドルへキャプチャする。
- フォーカスしたハンドルでは左右矢印キーにより10px単位で幅を変更できる。
- 列の最小幅は48pxとする。初期表示で実測した各列の幅を基準に、変更した列幅と表全体の幅を直接更新する。
- コード・差分表示で読み込まれ、列幅を計測できない場合は、本文の`hidden`属性の変更を監視し、Preview表示後に列幅とハンドルを初期化する。初期化成功後は監視を解除し、以降の表示切り替えでは変更済みの列幅を保持する。横スクロール用コンテナは先に作成し、固定ヘッダーと共有する。
- 表がない文書にはスタイルとスクリプトを埋め込まない。
- 本文幅を超えた表は専用コンテナ内で横スクロールできる。
- ハンドルの高さは表本体の実測高に合わせ、表の下余白や横スクロールバーへ線をはみ出させない。
- 明示的な`colgroup`または結合された見出しセルを持つ表には手を加えない。

## ファイル

- `index.ts`: 有効時だけスタイルとブラウザスクリプトを返すFeature内部エントリポイント。
