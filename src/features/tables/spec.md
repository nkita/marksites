# tables仕様

## 責務

Markdown本文内の表に関する列ソート、列幅変更、固定見出し、CSVコピーを一つのFeatureとして構成し、ブラウザスクリプトの実行順を所有する。

## 構成

- ソートを最初に初期化し、見出しの操作状態とインジケーターを追加する。
- 列幅変更を次に初期化し、ソートUIを含む見出し幅を基準にする。
- 固定見出しをその後に初期化し、ソートと列幅変更が適用済みの表を複製する。
- 表がない場合はスタイルとスクリプトを返さない。

個別機能の動作仕様は各内部Featureの`spec.md`に従う。

## CSVコピー（`copy.ts`）

表とコピー操作を幅fit-content・最大幅100%のコンテナにまとめ、表の右上に枠のないコピーアイコン付きの「コピー」リンクを配置する。小さい表では表の右端に揃い、広い表では横スクロール領域の右端に揃う。固定見出しには複製しない。初期化は既存の表機能の後で行う。

クリック時の行順で見出し・本文・フッターをCSVへ変換する。各セルを二重引用符で囲み、内部の二重引用符を二重化し、行区切りにはCRLFを使う。セルの空白・改行・カンマ・空セルは保持し、リンクや装飾はテキスト、brは改行、画像はaltにする。操作UIは含めない。結合セルのある表と行のない表は対象外にする。

Clipboard APIを優先し、未対応または拒否時は一時textareaとexecCommandへフォールバックする。後処理でフォーカスと選択を復元し、成功時はアイコンを保ってラベルを「コピーしました」へ変更し、1600ms後に「コピー」へ戻す。連続コピー時は復帰タイマーを更新する。コードブロックと同様に成功・失敗をaria-labelでも通知し、失敗時はラベルを変更しない。リンクは再クリックでき、処理中の重複実行とページ内ジャンプは防ぐ。複数の表は独立してコピーできる。表のない文書にはアセットを追加しない。registryはtablesのscriptsからHTTP配信時の許可スクリプトを取得する。

コピーリンクは13px相当のグレーの文字と14pxアイコンを用い、リンク色や下線は付けず、ツールチップは「表をCSVとしてコピー」とする。リンクのホバー中は対象表だけに薄い青色の2px枠を内側へ描画し、表の幅や配置を変えない。
