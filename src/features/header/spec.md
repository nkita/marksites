# header仕様

## 責務

固定ヘッダー、文書情報、テーマ切り替え、生成UIの言語切り替えを所有する。

## ファイル

- `index.ts`: ヘッダーFeatureを構成する内部エントリポイント。

明示的なテーマ選択はOSの配色設定に依存せず、本文、コードブロック、注釈ハイライトで使用する配色変数をライト・ダーク双方について定義する。ダークテーマでは通常文字、補助文字、境界、アクセントのコントラストを確保する。

固定ヘッダーは左に濃色背景・白文字・角丸四角形のmarksitesロゴ、その右にファイルパス、更新日時、ファイル一覧ポップオーバー操作、右端にテーマと言語の操作とLayoutメニューを置く。従来の左端ファイルサイドバーボタンと右サイドバー単独ボタンは表示しない。Layoutメニューは選択後の状態を表す「すべて表示」「左＋本文」「本文＋右」「本文のみ」を、表示領域の多い順にラジオ項目として示し、現在の左右状態をチェック表示する。メニューは外側のクリックまたはEscapeで閉じ、キーボード操作時はトグルへフォーカスを戻す。更新日時はファイルパスの右隣へ細い縦区切り線と補助色で表示し、パスと同じ28px行ボックスの中央へ揃える。ファイルパスはUI言語の翻訳対象にしない。ブラウザの文書タイトルは`marksites | <ファイル名>`形式とする。

固定ヘッダーは高さ56pxとし、本文、右サイドバー、見出しscroll margin、ファイルサイドバーの上端を高さに合わせる。狭い画面では現在ファイル名を優先し、祖先パンくず、コピー操作、更新日時を隠す。
