# header仕様

## 責務

固定ヘッダー、文書情報、テーマ切り替え、生成UIの言語切り替えを所有する。

## ファイル

- `index.ts`: ヘッダーFeatureを構成する内部エントリポイント。

明示的なテーマ選択はOSの配色設定に依存せず、本文、コードブロック、注釈ハイライトで使用する配色変数をライト・ダーク双方について定義する。ダークテーマでは通常文字、補助文字、境界、アクセントのコントラストを確保する。

固定ヘッダーは左に濃色背景・白文字・角丸四角形のmarksitesロゴ、その右にファイルパス、更新日時、ファイル一覧ポップオーバー操作、右端にショートカット案内、テーマ、言語の操作とLayoutメニューを置く。ショートカット案内のトグルはキーボード型アイコンとし、目次、ファイルツリー、文書表示切り替え、Layoutメニューに表示するすべてのキーバッジと案内文を一括で表示・非表示にする。ショートカット操作自体は無効にせず、表示状態を`shortcuts`クエリパラメータで同一文書および文書間リンクに引き継ぐ。既定は非表示とし、明示的に表示した場合だけ`shortcuts=visible`を付与する。従来の左端ファイルサイドバーボタンと右サイドバー単独ボタンは表示しない。Layoutトグルはメニュー項目と同じ3ペイン形式のアイコンを使い、現在の左右サイドバー表示状態を反映する。トグル内のアイコン外形はテーマ・言語切り替えアイコンと同じ16px四方とする。Layoutメニューは選択後の状態を表す「すべて表示」「左＋本文」「本文＋右」「本文のみ」を、表示領域の多い順にラジオ項目として示す。現在状態のチェックは項目の左端に置き、未選択項目にも同じ固定幅の領域を確保して内容位置を揃える。メニューは外側のクリックまたはEscapeで閉じ、キーボード操作時はトグルへフォーカスを戻す。更新日時はファイルパスの右隣へ細い縦区切り線と補助色で表示し、パスと同じ28px行ボックスの中央へ揃える。ファイルパスはUI言語の翻訳対象にしない。ブラウザの文書タイトルは`marksites | <ファイル名>`形式とする。

Layoutメニューの各項目には上から`Q`、`W`、`E`、`R`のキーバッジを表示し、メニューの開閉状態にかかわらず対応するレイアウトへ切り替える。フォーム入力、選択UI、編集可能領域での入力中、修飾キー併用時、キーリピート中はLayoutショートカットを無効にする。

固定ヘッダーは高さ56pxとし、本文、右サイドバー、見出しscroll margin、ファイルサイドバーの上端を高さに合わせる。狭い画面では現在ファイル名を優先し、祖先パンくず、コピー操作、更新日時を隠す。
