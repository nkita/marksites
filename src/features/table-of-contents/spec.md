# table-of-contents仕様

## 責務

GitHub互換の見出しID、目次マークアップ、現在見出しの追従動作を所有する。

既定では`#`から`######`まで、すべての見出しレベルを目次へ表示する。`minDepth`と`maxDepth`が明示された場合はその範囲だけを対象にする。

## ファイル

- `index.ts`: table-of-contents Featureの内部エントリポイント。

本文スクロールに応じて現在位置のリンクへ`aria-current="location"`を付け、文書の最下部へ到達した場合は最後の見出しを現在位置とする。アクティブリンクが目次の表示範囲外へ移動した場合は目次パネル内を自動スクロールして中央付近へ表示する。差分表示中は`diff-`接頭辞付き、コード表示中は`markdown-source-`接頭辞付きの見出しを追跡する。目次リンクを選んだ場合も表示モードを維持したまま、現在の表示に対応する見出しへスクロールし、先頭項目へ移動する場合は文書の最上部までスクロールする。入力欄や編集可能領域にフォーカスがない場合、`J`キーで一つ次、`K`キーで一つ前の見出しへ移動する。キーの長押しによるリピート入力にも対応し、連続入力時はスクロール位置の再計算を待たず、直前に移動した見出しを基準に続けて移動する。

目次は見出し階層に対応する入れ子の`ul`として生成する。目次見出しと項目テキストは左寄せにする。最上位項目には左罫線を表示せず、子階層は左側に17pxの余白を取って薄い縦線と横線で接続し、途中の項目を`├─`、末尾を`└─`に相当する直角の枝として表現する。項目間で線が途切れる余白は設けない。現在位置は単色の背景だけで示し、濃いアクセント縦線やグラデーションは表示しない。ホバー時と現在位置の背景領域は四隅を4pxの控えめな角丸とする。
