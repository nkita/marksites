# sidebar仕様

## 責務

目次とコメントを収容する右サイドバーのマークアップ、スタイル、ブラウザ動作を所有する。

## ファイル

- `index.ts`: サイドバーFeatureを構成する内部エントリポイント。

右サイドバーは固定ヘッダーと上下余白を除いたビューポート高を明示的な高さとして持ち、タブ領域を固定したまま選択中のパネルだけを縦スクロールさせる。サイドバー本体、パネルコンテナ、選択中のパネルは`min-height: 0`と残り高さを受け取るflex指定を持ち、長い目次やコメントが親要素を押し広げないようにする。

選択中のタブは`sidebar-tab`クエリパラメータへ保存し、同一ホスト・プロトコルのHTMLリンクへ引き継ぐ。遷移先に該当タブがない場合は、そのページの既定タブ（目次があれば目次、なければコメント）を選択する。
