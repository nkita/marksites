# sidebar仕様

## 責務

目次とコメントを収容する右サイドバーのマークアップ、スタイル、ブラウザ動作を所有する。

目次タブには見出し移動のショートカットとして「次へ：J」「前へ：K」を横一列のコンパクトなキー表示で併記する。

## ファイル

- `index.ts`: サイドバーFeatureを構成する内部エントリポイント。

右サイドバーは固定ヘッダーと上下余白を除いたビューポート高を明示的な高さとして持ち、タブ領域を固定したまま選択中のパネルだけを縦スクロールさせる。タブ文字は左寄せとし、選択中タブの下にアクセント線を表示しない。サイドバー本体、パネルコンテナ、選択中のパネルは`min-height: 0`と残り高さを受け取るflex指定を持つ。

901px以上では右サイドバーを初期表示し、ヘッダーのLayoutメニューから表示・非表示を切り替える。非表示時は本文グリッドから右カラムを除いて本文を広げる。

900px以下では右サイドバーを本文グリッドから外し、Layoutメニューの右表示を含む項目から開くオーバーレイ型ポップアップにする。ポップアップは固定ヘッダー直下に配置し、ビューポート高の70%を上限として選択中のパネルを内部スクロールさせる。背景オーバーレイ、Escape、目次リンクの選択で閉じる。コメント表示イベントではコメントタブを選択して同じポップアップを開く。

選択中のタブは`sidebar-tab`、デスクトップの非表示状態は`document-sidebar=closed`クエリパラメータへ保存し、同一ホスト・プロトコルのHTMLリンクへ引き継ぐ。遷移先に該当タブがない場合は、そのページの既定タブ（目次があれば目次、なければコメント）を選択する。モバイルのポップアップ開閉は一時的な状態としてURLへ保存しない。
