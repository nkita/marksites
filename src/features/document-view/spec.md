# document-view仕様

## 責務

通常のHTML本文、元のMarkdown、前回ビルドとの差分という文書表示を排他的に切り替え、表示状態をURLとサイト内リンクへ反映する。

## ファイル

- `index.ts`: Markdown原文、本文右上の切り替え操作、表示状態を統合するスタイルとブラウザ動作を生成する。

Markdown原文は生成時に行へ分割してHTMLエスケープし、編集不可の`pre`と`code`として埋め込む。各行にはCSS counterによる選択対象外の行番号を表示し、長い行は原文領域の幅に合わせて空白を維持したまま折り返す。折り返した行でも行番号ガターの背景と縦罫線を論理行の末尾まで連続させる。原文領域と`pre`には外枠、角丸、shadowを付けない。外部アセットや実行時のMarkdown取得には依存しない。

原文の記号と文字列を保持したまま、構造を視覚的に判別できる装飾を加える。ブロック要素はATX・Setext見出し、引用、箇条書き・番号付き・タスクリスト、区切り線、表、フェンス・インデントコード、HTML、リンク定義を識別する。インライン要素は太字、斜体、取り消し線、コード、リンク、画像、自動リンクを識別する。見出しと太字は太字表示し、引用・表・コードブロックには本文と異なる背景を付ける。リンクはMarkdown記法を表示したままクリック可能にし、相対`.md`・`.markdown`リンクは`.html`へ変換する。`http`、`https`、`mailto`と相対URL以外の明示的なスキームはリンク化せず、すべての原文と属性値をHTMLエスケープする。原文の見出し行には通常本文と同じGitHub互換slugを接頭辞付きIDとして設定し、コードビュー中の目次操作はビューを切り替えず該当行へスクロールする。

共通の本文枠は操作行と現在選択されている本文を一体で囲む。本文上部には将来の操作追加を想定した全幅の操作行と下境界線を置く。左端に`Preview`と`コード`を独立したタブ風ボタンとして常設し、選択状態をアクセント色の下線と`aria-pressed`で示す。hover背景は四隅を丸める。文字列置換は`margin-left:auto`で右端へ分離する。Markdown原文の`pre`には本文枠と重なる内枠や操作行との上余白を追加しない。

`document-view`クエリパラメータはMarkdown表示を`markdown`、差分表示を`diff`で表し、通常HTML表示では省略する。同一ホスト・プロトコルのHTMLリンクへ現在の表示意図を引き継ぐ。差分のないページで`diff`を受け取った場合は通常本文を表示しつつ、差分のある移動先に備えてURL上の意図を保持する。

文字列置換は表示状態にかかわらず操作行の右端へ残し、通常HTML表示以外では非活性にする。コードの1行目には操作行との間隔を設け、その空きにもガター境界線を連続して描画する。行番号ガターと上部の境界線は横スクロール中も本文枠の左端へsticky表示する。目次とコメントサイドバーは原文表示でも維持し、目次リンクを選ぶとHTML表示へ戻して対象見出しへ移動する。
