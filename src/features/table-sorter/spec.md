# table-sorter仕様

## 責務

Markdown本文の表へ、外部依存のないクライアント側列ソートを追加する。

## 動作

- 結合されていない先頭見出し行を持ち、1つ以上の本文行グループがある表を対象とする。
- 見出しをクリックするたびに、昇順、降順、Markdownに記述された元の順序へ切り替える。
- 別の列を選択した場合は、その列の昇順から開始する。
- `Intl.Collator`のnumeric比較を利用し、文字列を大文字小文字を区別せず自然順で比較する。同値の行は元の順序を維持する。
- EnterまたはSpaceキーでもソートでき、`aria-sort`と視覚インジケーターを現在状態へ同期する。
- 上下シェブロンのSVGインジケーターは見出し右端の固定領域で垂直中央へ揃え、列固有の文字揃えを変更しない。hover時は控えめな背景、選択時はアクセント色と背景で状態を示す。
- 見出し内のボタン、リンク、フォーム要素の操作ではソートしない。
- 表がない文書にはスタイルとスクリプトを埋め込まない。

## ファイル

- `index.ts`: 有効時だけソート用スタイルとブラウザスクリプトを返すFeature内部エントリポイント。
